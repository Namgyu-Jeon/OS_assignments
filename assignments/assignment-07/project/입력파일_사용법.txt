입력 파일을 바꾸어 실행하는 방법

1. 준비된 입력 파일

input1.txt ~ input9.txt는 기본 예제 입력 9개를 그대로 복사한 파일이다.
input-custom.txt는 직접 값을 바꾸어 볼 수 있도록 추가한 연습용 입력이다.
연습용 입력은 기본 예제와 별도로 작성했으며, 처음에는 다음 결과가 나온다.
Result: Safe --> P_02 P_01 P_00

Visual Studio의 솔루션 탐색기에서 safety 아래의 Input Files를 펼치면
이 파일들을 열어 볼 수 있다. 프로젝트를 이미 열어 둔 경우 다시 불러와야
추가된 목록이 표시될 수 있다.

2. Visual Studio에서 다른 파일로 실행하기

솔루션 탐색기에서 safety 프로젝트를 마우스 오른쪽 버튼으로 누른 뒤
속성 > 구성 속성 > 디버깅 > 명령 인수에서 입력 파일 이름을 바꾼다.
예를 들어 다음과 같이 입력하면 두 번째 샘플을 검사한다.

"$(ProjectDir)input2.txt"

직접 수정한 입력을 검사하려면 다음과 같이 입력한다.

"$(ProjectDir)input-custom.txt"

설정을 적용한 뒤 Ctrl+F5로 실행한다. 프로젝트의 기본 입력은 input1.txt다.
Debug와 Release에서 모두 바꾸려면 속성 창의 구성을 '모든 구성'으로 선택한다.

3. 터미널에서 실행하기

code 폴더에서 PowerShell을 열고 원하는 파일을 지정한다.

.\bin\x64\Release\safety.exe input2.txt
.\bin\x64\Release\safety.exe input-custom.txt

검사할 파일은 한 번에 하나씩 지정한다. 파일 이름과 경로에 공백이 있으면
"새 입력.txt"처럼 큰따옴표로 감싼다.

4. 직접 입력 파일 만들기

input-custom.txt를 수정하거나 다른 이름으로 복사해 새 입력을 만들 수 있다.
첫 줄의 두 숫자는 순서대로 자원 종류 수와 프로세스 수다.
Allocation은 현재 각 프로세스가 가진 자원 개수이고,
Max는 각 프로세스가 필요로 할 수 있는 최대 자원 개수다.
Available은 현재 남아 있는 자원 개수다.

각 표의 자원 이름과 순서가 같아야 하며, Allocation과 Max의 프로세스 이름과
순서도 같아야 한다. 값은 0 이상의 정수로 적고, 각 칸의 Max는 Allocation보다
크거나 같아야 한다. 행과 열을 늘렸다면 첫 줄의 두 숫자도 함께 바꾼다.
공백이나 탭으로 칸을 구분하며 설명 문장은 입력 파일 안에 적지 않는다.

새 파일은 터미널에서 파일 이름을 지정하면 바로 사용할 수 있다.
솔루션 탐색기에도 표시하려면 Input Files에서 마우스 오른쪽 버튼을 누르고
추가 > 기존 항목으로 해당 파일을 등록한다.

결과는 입력된 숫자로 계산한다. 검증용 정답 파일은 실행에 필요하지 않다.

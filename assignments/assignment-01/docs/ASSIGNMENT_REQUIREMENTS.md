# 과제 요구사항 정리

[과제 1 보고서로 돌아가기](../README.md)

## 1. 과제 목적

첫 번째 프로그래밍 과제의 목적은 Windows 환경과 Visual Studio Community를 이용해 간단한 콘솔 프로그램을 작성하고, 프로젝트 생성부터 빌드·실행·문서화까지의 기본 과정을 경험하는 것입니다.

강의 자료와 설명에는 Visual Studio Community 2021과 2022가 함께 언급되어 있습니다. 이 제출본은 별도로 확정한 실제 개발 환경인 **Visual Studio Community 2026, C++17, Release/x64**를 기준으로 작성하고 검증했습니다.

## 2. 프로그램 기능

- 최대 단수 N을 명령행 인수로 받습니다.
- 1단부터 N단까지 출력합니다.
- 단 `d`는 `d x 1`부터 `d x d`까지만 출력합니다.
- 한 묶음에는 다섯 단을 가로로 배치합니다.
- 1~5단 다음에는 6~10단, 그다음에는 11~15단을 출력합니다.
- 실행 파일 이름은 `multi.exe`입니다.

기본 과제에서 요구한 형식에 더해 잘못된 입력의 재입력 처리, 숫자 자릿수에 따른 공통 열 정렬, 큰 출력에서의 불필요한 메모리 사용 감소를 구현했습니다.

## 3. 제출과 문서 형식

강의 설명 기준 제출물은 크게 다음 두 부분입니다.

1. Visual Studio 프로젝트 전체가 포함된 소스 코드 ZIP
2. 시스템·테스트·사용자·자기 평가 내용을 담은 문서

빌드된 Debug 폴더와 캐시는 ZIP 용량을 줄이기 위해 제외할 수 있습니다. 실제 과제 제출에서는 소스 프로젝트 ZIP을 별도로 제출하고, PPT 대신 허가된 GitHub 보고서의 과제별 링크를 제공합니다. 제출 기한은 Blackboard 공지를 기준으로 확인해야 합니다.

## 5. 채점 기준과 강의 안내

강의 설명에서 제시된 기본 채점 비중은 다음과 같습니다.

| 평가 영역 | 비중 | 확인 내용 |
|---|---:|---|
| 실행 정확성 | 40% | 요구한 형식으로 정상 실행되는가 |
| 프로그래밍 스타일 | 20% | 모듈화, 가독성, 주석, 알고리즘 효율성 |
| 시스템 문서 | 20% | 구조와 알고리즘을 이해할 수 있게 설명했는가 |
| 테스트 문서 | 10% | 실제 실행 결과와 화면 증거가 있는가 |
| 사용자 문서 | 10% | 다른 사람이 빌드하고 실행할 수 있는가 |

강의에서는 지각 제출을 허용하지 않으며 기한을 넘기면 0점 처리한다고 안내했습니다. 조기 제출은 하루당 5점, 최대 20점의 가산점, 프로그램 발표는 10점의 가산점이 안내되었습니다. 정확한 날짜와 적용 여부는 해당 학기의 Blackboard 공지를 우선합니다.

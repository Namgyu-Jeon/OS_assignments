# Handoff Playbook

When work pauses, preserve a concise and verifiable restart point.

Update `CURRENT_STATE.md` with:

- full baseline and current commit;
- branch and working-tree state;
- exact changed files that must be preserved;
- approved scope and exclusions;
- completed focused/full/manual checks;
- first unresolved failure with the meaningful log excerpt redacted;
- decisions already made and decisions still required;
- next safe command or read-only inspection.

Do not claim completion, create a convenience commit, discard partial work, or paste the full private conversation. A handoff should let another agent resume from repository evidence rather than memory.

# Minimal fix approval

```text
원인 분석과 다음 최소 수정 범위를 승인한다.

확정 원인:
- [원인]

허용 변경:
- [파일]
- [정확한 동작]

유지해야 할 조건:
- [보안·무결성·호환성·데이터 불변 조건]

금지:
- 제품 범위 확장
- 검증 완화 또는 오류 무시
- 새 dependency
- 관련 없는 코드·workflow·packaging 변경
- commit·push·PR·merge·release

원래 실패 사례와 회귀 테스트를 먼저 실행하고, 통과하면 전체 품질 게이트를 한 번 실행해라.
실패가 승인 범위를 벗어나면 변경을 보존하고 원인과 diff만 보고해라.
```

# Pause and handoff

```text
오늘 작업을 여기서 중단한다.

현재 파일과 Git 상태를 변경하지 말고 다음 세션이 추측 없이 재개할 수 있도록 인수인계 내용을 정리해라.

- branch와 full commit
- working tree와 반드시 보존할 변경 파일
- 승인된 목표·완료된 작업·남은 작업
- 실행한 focused/full/manual 검증과 결과
- 첫 unresolved error와 원인 상태
- 금지된 우회책과 유지해야 할 정책
- 다음 안전한 read-only 확인과 권장 첫 작업

비밀값·개인 경로·실제 사용자 데이터·전체 로그·원문 대화는 기록하지 마라.
commit·push·reset·rollback은 하지 마라.
```

# Project kickoff

```text
이 저장소에서 새로운 프로젝트를 시작한다.

먼저 AGENTS.md, CLAUDE.md, PROJECT_INIT.md와 현재 Git 상태를 읽기 전용으로 확인해라.
아직 파일을 만들거나 수정하지 마라.

내가 해결하려는 문제는 다음과 같다.
- 제품 아이디어: [아이디어]
- 대상 사용자: [사용자]
- 가장 중요한 첫 결과: [실제 end-to-end 결과]
- 현재 알고 있는 제약: [플랫폼·예산·기술·법적 범위]

누락된 제품 결정을 질문하고, 다음을 제안해라.
- 제품 범위와 명시적 제외 범위
- 가장 작은 실제 M1 완료 조건
- 단계별 마일스톤
- 권장 아키텍처와 기술 선택
- 데이터·보안·개인정보 경계
- 테스트·수동 검증·배포 전략
- 생성·수정할 파일
- 위험과 중단 조건

계획과 승인 요청까지만 진행하고 구현하지 마라.
```

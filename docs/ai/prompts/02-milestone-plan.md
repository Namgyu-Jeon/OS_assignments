# Milestone planning

```text
다음 마일스톤 [MILESTONE_ID: 이름]을 계획해라.

목표:
- [사용자 또는 기술 결과]

필수 완료 조건:
- [조건]

제외 범위:
- [이번에 하지 않을 일]

현재 저장소·Git·관련 문서·기존 구현을 읽기 전용으로 확인하고, 기존 변경을 보존해라.
중복 구현을 피하고 실제 코드 기준으로 다음을 제안해라.

- 사용자 흐름
- 정확한 구현 범위와 예상 파일
- 재사용할 기존 구조
- 데이터·보안·플랫폼·의존성 위험
- 관련 테스트와 완료 시 전체 검증
- 수동 검증 절차
- 롤백 기준
- 중단 조건

아직 변경하지 말고 승인 요청으로 끝내라.
```

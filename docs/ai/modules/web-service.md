# Web Service Module

- Define browser, API, worker, database, and third-party trust boundaries.
- Validate and authorize every server-side operation; client-side checks are not security controls.
- Keep secrets server-side and use least-privilege service credentials.
- Specify authentication, session expiry, CSRF, CORS, rate limits, audit logs, retention, backup, and deletion policy.
- Test API contracts, idempotency, retries, timeouts, partial failure, and migration compatibility.
- Separate preview/staging deployment authority from production deployment authority.

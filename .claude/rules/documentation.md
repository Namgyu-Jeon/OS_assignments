# Documentation rules

- Record only verifiable facts, approved decisions, evidence, and clearly labeled recommendations.
- Do not include secrets, personal paths, private URLs, raw conversations, or unredacted logs.
- Keep links relative when the destination is inside the repository.
- Update current state, decisions, tests, and changelog only when their truth changed.
